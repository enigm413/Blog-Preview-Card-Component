# Blog Preview Card Component

A simple static blog preview card component built with HTML and CSS. This project features a modern card design with illustration, category tag, publication date, and author information.

## Preview

The component displays a white card with rounded corners containing:

- An illustration image with rounded borders
- A category tag badge
- Publication date
- A bold, hoverable title
- Descriptive text
- Author profile section with avatar and name

## Features

- 🎨 Clean and modern UI with bold shadow effect
- 🔤 Google Fonts integration (Figtree font family)
- 💫 Interactive hover state on title
- 📱 Responsive image scaling
- ♿ Semantic HTML structure
- 🎯 Flexbox layout for author section

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Figtree)

## Design Specifications

### Colors

- **Background**: hsl(47, 88%, 63%) - Yellow
- **Card Background**: hsl(0, 0%, 100%) - White
- **Title Color**: hsl(0, 0%, 7%) - Near black
- **Text Color**: hsl(0, 0%, 42%) - Gray
- **Tag Background**: hsl(47, 88%, 63%) - Yellow
- **Hover Color**: hsl(47, 88%, 63%) - Yellow

### Typography

- **Font Family**: Figtree (Google Fonts)
- **Base Font Size**: 16px
- **Title Font Size**: 24px
- **Title Font Weight**: 800
- **Tag Font Weigh**t: 700
- **Date/Text Font Weight**: 500
- **Author Name Font Weight**: 700

### Layout

- **Card Width**: 365px
- **Card Padding**: 20px
- **Border Radius**: 16px (card), 4px (tag)
- **Box Shadow**: 8px 8px solid black shadow
- **Border**: 1.4px solid black (left and top)

### Interactive Features

- **Title Hover Effect**: The title changes to yellow and cursor becomes pointer on hover
- **Responsive Images**: All images scale properly within their containers

## Customization

You can easily customize the component by modifying the CSS variables in `style.css`:

- Change colors by updating the HSL values
- Adjust card dimensions by modifying the width and padding
- Modify border radius for different corner styles
- Update font sizes for different text emphasis
